Escenario F2-3: Puede Teseo liberar a Andromeda?
Condiciones:
  Teseo tiene el favor de Atenea
  Teseo tiene el favor de Hermes
  Teseo tiene el favor de Hades
  Teseo tiene el favor de Hefesto
Si, Teseo puede liberar a Andromeda debido a que:
  Teseo localiza a las Grayas debido a tener el favor de Hermes y Atenea.
  Teseo obtiene CascoHades debido a tener el favor de Hades.
  Teseo obtiene Capacidad Invisibilidad debido a tener CascoHades.
  Teseo obtiene (roba) DienteGrayas de las Grayas debido a tener Invisibilidad (CascoHades) y las Grayas localizadas.
  Teseo devuelve DienteGrayas a las Grayas a cambio de saber donde estan las Ninfas.
  Teseo localiza a las Ninfas debido a intercambio de DienteGrayas con las Grayas.
  Teseo obtiene ZurronMagico debido a las Ninfas localizadas.
  Teseo obtiene SandaliasAladas debido a las Ninfas localizadas.
  Teseo obtiene Capacidad Vuelo debido a tener SandaliasAladas.
  Teseo obtiene HozAcero debido a tener el favor de Hermes.
  Teseo obtiene EscudoBronce debido a tener el favor de Atenea.
  Teseo obtiene EscudoEspejo debido a tener el favor de Hefesto y el EscudoBronce.
  Teseo obtiene Capacidad Reflejo debido a tener EscudoEspejo.
  Ceto queda libre debido al enojo de Poseidon hacia Casiopea.
  Andromeda queda presa debido a estar Ceto libre.
  Teseo mata a Medusa debido a tener EspadaTeseo, Espejo (EscudoEspejo), Invisibilidad (CascoHades) y Vuelo (SandaliasAladas).
  Teseo obtiene CabezaMedusa debido a matar a Medusa.
  Teseo no muere al obtener CabezaMedusa por tener ZurronMagico.
  Teseo obtiene Capacidad Petrificacion debido a tener CabezaMedusa.
  Teseo mata a Ceto debido a tener CabezaMedusa.
  Teseo obtiene CabezaCeto debido a matar a Ceto.
  Teseo libera a Andromeda debido a matar a Ceto.
